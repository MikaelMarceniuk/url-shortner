# url-shortener

White-label URL shortener built for multi-tenant SaaS. Each company gets their own dashboard at their subdomain, their own branded short links, and full UTM configuration — all running on shared infrastructure.

```
shortner.codeui.com       → CodeUI's dashboard
link.codeui.com/abc123    → short link generated by CodeUI
```

## Getting Started

### Prerequisites

- [mise](https://mise.jdx.dev/) — manages Node, Bun and pnpm versions
- MongoDB running locally or a connection string (Atlas, etc.)

### Setup

```bash
# Install tool versions declared in mise.toml
mise install

# Install dependencies
pnpm install

# Copy env files
cp apps/web/.env.example apps/web/.env
cp apps/api/.env.example apps/api/.env
```

Fill in the `.env` files (see [Environment Variables](#environment-variables) below), then:

```bash
# Run all apps in parallel
pnpm --recursive start:dev

# Or individually
cd apps/api && bun start:dev
cd apps/web && bun start:dev
```

## How Multi-Tenancy Works

The system identifies the tenant from the request hostname. There are two types of hostnames:

- **`instance_host`** — where the dashboard lives (`shortner.codeui.com`). Resolved by the Next.js middleware.
- **`link_domain`** — where short links are served (`link.codeui.com`). Resolved by the Elysia redirect engine.

Every database query is scoped to a `tenant_id`. There are no cross-tenant queries.

Custom domains are verified via DNS TXT record before being activated. SSL is handled automatically by Caddy using Let's Encrypt on-demand TLS — no manual certificate management needed.

---

## Redirect Flow

```
Visitor clicks link.codeui.com/abc123
        ↓
Caddy receives request, issues SSL if needed
        ↓
Elysia reads header host: "link.codeui.com"
Finds tenant that owns this domain
        ↓
Looks up slug "abc123" scoped to that tenant
        ↓
Appends UTM params to destination URL
        ↓
301 / 302 redirect → https://codeui.com/product?utm_source=...
        ↓
Umami on the destination site tracks the visit via UTM params
```

Analytics is handled entirely by Umami on the destination site. The shortener only ensures UTM parameters arrive correctly on the destination URL.
